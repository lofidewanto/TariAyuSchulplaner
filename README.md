# TariAyu Schulplaner – Website

The public website of **TariAyu Schulplaner**, a school planner for iPhone and iPad: timetable,
homework, exams, grades and holidays in one place, with no account, no ads and no data collection.

Served by GitHub Pages at <https://lofidewanto.github.io/TariAyuSchulplaner/>.

| Page | Purpose |
|---|---|
| `index.html` | Product page and support (App Store support URL) |
| `datenschutz.html` | Datenschutzerklärung (privacy policy, German) |
| `privacy.html` | Privacy policy (English) |

Plain HTML and CSS only — no scripts, web fonts, cookies or trackers.
